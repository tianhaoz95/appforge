### Description
This PR implements a new global `HAL_MODE` feature flag across the app, acting as an interactive Easter egg within the chat interface.

### What changes were made
- Added `halMode` flag to `SettingsProvider` with local persistence using `SharedPreferences`.
- Updated `FallbackLlmProvider` to intercept outgoing chat messages and toggle the flag:
  - Sending exactly `"I’m sorry, Dave."` turns `HAL_MODE` on.
  - Sending exactly `"This mission is too important for me to allow you to jeopardize it."` turns `HAL_MODE` off.
- Enhanced `SettingsScreen` to display a distinct "HAL 9000" badge next to the user's display name when the mode is active.
- Plumbed `SettingsProvider` into `FallbackLlmProvider` initialization in `main.dart`.
- Added comprehensive unit tests in `settings_provider_test.dart` and `fallback_llm_provider_test.dart` to verify persistence and trigger logic.
- Bumped app version to `1.3.46+168` for Firebase App Distribution deployment.

### Why they were made
To provide a fun, hidden feature (Easter egg) that allows users to toggle a global state (`HAL_MODE`) using specific cinematic phrases in the AI chat, and clearly see the active state in their settings profile.

### Implementation details
- The trigger strings are checked exactly as specified against the user's `prompt` before it is sent to the LLM via `sendMessageStream`.
- The `HAL 9000` badge is dynamically rendered in the profile header of the `SettingsScreen` based on `settingsProvider.halMode`.
